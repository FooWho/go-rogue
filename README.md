# Go Rogue
A Go implementation of the Roguelike tutorial from [Roguelike Tutorials](https://rogueliketutorials.com).

Source code is under the GPLv3.

The file dejavu10x10_gs_tc.png in the assets directory is, to the best of my knowledge, in the public domain. It was obtained from [Roguelike Tutorials](https://rogueliketutorials.com). The file dejavu10x10_gs_tc_transparent.png is an alteration I created to set the font on a transparent background.

The file monochrome-transparent_packed.png in the assets directory is under CC0 1.0. It was obtained from [kenney.itch.io](https://kenney.itch.io).
